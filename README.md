# 矩阵初等行变换可视化工具

这是一个用于可视化矩阵初等行变换过程的Web应用，可以帮助学习线性代数的学生直观地理解矩阵变换过程。

## 功能特点

- 创建任意大小的矩阵（最大10×10）
- 通过图片识别输入矩阵（OCR功能）
- 执行高斯-约旦消元法
- 逐步展示变换过程
- 自动播放变换步骤

## 如何分享给他人

有多种方式可以分享这个工具给其他人：

### 方法1：本地网络分享（适合同一网络内的用户）

1. 安装Node.js（如果尚未安装）：从[Node.js官网](https://nodejs.org/)下载并安装
2. 打开命令提示符或PowerShell，进入项目目录
3. 安装依赖：
   ```
   npm install
   ```
4. 启动服务器：
   ```
   npm start
   ```
5. 服务器启动后，可以通过以下方式访问：
   - 本机访问：http://localhost:3000
   - 同一网络内的其他设备访问：http://你的IP地址:3000（可以通过运行`ipconfig`命令查看你的IP地址）

### 方法2：部署到免费托管平台（适合互联网分享）

#### 使用Netlify部署（推荐，最简单）

1. 注册[Netlify](https://www.netlify.com/)账号
2. 点击"New site from Git"
3. 选择GitHub作为Git提供商并授权
4. 选择包含项目的仓库
5. 在构建设置中，将发布目录设置为"."（点号，表示根目录）
6. 点击"Deploy site"
7. 部署完成后，Netlify会提供一个URL（例如：https://your-site-name.netlify.app）
8. 将此URL分享给他人即可
